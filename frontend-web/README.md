# REVENT | Frontend 

The frontend for **REVENT**, a digital banking simulator focused on scam prevention and safer financial transactions.

Built using **React + Vite**, with responsive layouts for desktop and mobile.

##  Tech Stack

- React
- Vite
- JavaScript (JSX)
- CSS
- React Router
- Lucide React

##  Getting Started

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173/`).

##  Features

- Responsive banking dashboard
- Account balances and transaction history
- Banking quick actions
- Desktop and mobile navigation
- Floating simulation control panel
- Banking service pages

##  Development Status

**Sprint 1: Frontend Development**

Currently using mock data and frontend-only interactions. Backend and database integration are planned for a later sprint.
